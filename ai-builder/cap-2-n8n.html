1O que é o n8n

Uma automação é uma receita: "quando X acontecer, faça Y e Z". Como o n8n representa isso?

O n8n é uma ferramenta de automação visual. Você monta um workflow (fluxo) ligando nós numa tela. O primeiro nó é o gatilho (trigger): um webhook, um horário, um formulário, um e-mail novo. Os seguintes fazem ações: ler planilha, chamar API, filtrar, mandar mensagem, chamar um modelo de IA.

O conceito que mais confunde iniciante é o item. Cada nó recebe uma lista de itens (cada item é um JSON) e, em regra, roda uma vez para cada um. Se a planilha devolve 30 linhas, o nó seguinte recebe 30 itens e manda 30 mensagens. Isso é ótimo quando você quer, e um desastre quando não percebe.

Exemplo resolvido: quantas mensagens saem?
Gatilho: todo dia às 8h. Nó 1: lê a planilha de prazos e devolve 12 linhas.
Nó 2 (filtro): passa só as linhas com prazo para hoje. Sobram 3 itens.
Nó 3 (Telegram): roda uma vez por item. Saem 3 mensagens. Sem o filtro, sairiam 12.

2Onde rodar: nuvem ou o seu PC

O n8n tem duas formas de uso. Qual faz sentido para estudar?

n8n Cloud

Você cria a conta e usa no navegador. A página de preços (29/10/2026) mostra um teste gratuito com limites (1.000 execuções, sem cartão) e planos pagos depois. Bom para começar hoje.

Self-hosted (Community Edition)

A versão padrão do n8n é publicada no GitHub e você roda no seu computador ou servidor, sem pagar licença. O jeito recomendado é com Docker, que é o capítulo 4.

Sugestão da trilhaComece no Cloud nas semanas 2 e 3 para não travar na instalação. Na semana 4, depois do Docker, leve o mesmo fluxo para o seu PC.

Com expressões.

3Expressões: puxar dados de um nó para outro

Como escrever "Olá, Ana" quando o nome muda a cada item?

Em qualquer campo de um nó você pode escrever uma expressão entre chaves duplas. Dentro delas vale um JavaScript simplificado, e $json é o item atual que chegou do nó anterior. A documentação oficial usa o exemplo {{$json.body.city}}: o campo city dentro de body. É o caminho de JSON do capítulo 1, com $json na frente.

Erro comumO nome do campo mudou na origem (alguém renomeou a coluna da planilha) e a expressão continua apontando para o nome antigo. Resultado: campo vazio sem erro nenhum, ou erro ao ler algo de um objeto que não existe. Sempre abra a aba de entrada do nó e confira os nomes.

4Credenciais

Onde colocar a chave do Google, do Telegram ou do modelo de IA?

O n8n tem um lugar próprio para credenciais. Você cadastra uma vez (por chave de API ou por login OAuth, quando o serviço oferece) e escolhe a credencial no nó. Ela fica guardada separada do fluxo; quando você exporta o workflow em JSON para compartilhar, a chave não vai junto. É a aplicação da regra do capítulo 1: segredo fora da receita.

O nó de agente.

5IA dentro do fluxo: o nó AI Agent

Como colocar um modelo de linguagem no meio de uma automação, e não só no fim?

O n8n tem nós de IA. O mais usado é o AI Agent, que junta três peças: um modelo de chat (Claude, GPT, Gemini, conectados pela credencial), ferramentas que o agente pode decidir usar (consultar planilha, chamar uma API, buscar na web) e uma memória da conversa. Para tarefas sem decisão, como resumir ou classificar um texto, um nó de chamada direta ao modelo basta e é mais previsível.

Projeto guiado da semana: triagem de pedidos com IA

1. Gatilho

Nó Form Trigger (ou Webhook) com os campos nome, e-mail e mensagem.

2. Classificar

Nó de modelo de chat com o prompt: "Classifique a mensagem em uma destas categorias: orçamento, suporte, reclamação. Responda só com a categoria." e a mensagem via {{ $json.mensagem }}.

3. Decidir

Nó Switch: cada categoria segue um caminho. Trate também o caso "outra resposta", porque o modelo pode fugir do combinado.

4. Agir

Orçamento vira linha na planilha; reclamação manda alerta no Telegram; suporte gera resposta automática por e-mail.

5. Medir

Anote quanto tempo a triagem manual levava e quantos pedidos chegam por semana. É o número do seu portfólio (capítulo 9).

IA não é determinísticaO mesmo texto pode receber categorias diferentes em execuções diferentes. Peça saída curta e fechada, trate a resposta inesperada e teste com mensagens de verdade antes de ligar o fluxo em produção.

Tratamento de erro.

6Quando dá errado

Fluxo que falha em silêncio é pior que fluxo nenhum. Como ficar sabendo?

Três hábitos: (1) a aba Executions guarda cada execução com o dado que passou em cada nó, então reproduza o erro olhando a entrada do nó que quebrou; (2) monte um workflow separado começando pelo nó Error Trigger, que dispara quando outro fluxo falha, e mande um aviso para você; (3) em nós que chamam APIs instáveis, ative novas tentativas com espera.

7Fechamento do capítulo

Cola da prova

  • Workflow = gatilho + nós. Cada nó recebe uma lista de itens e roda uma vez por item.
  • Cloud para começar rápido; Community Edition self-hosted (com Docker) para rodar no seu PC.
  • Expressão: {{ $json.campo }} lê o item atual. Confira os nomes na aba de entrada.
  • Credenciais ficam no cofre do n8n, fora do workflow exportado.
  • AI Agent = modelo + ferramentas + memória. Para classificar ou resumir, a chamada direta basta.
  • Executions para investigar; Error Trigger para ser avisado.
