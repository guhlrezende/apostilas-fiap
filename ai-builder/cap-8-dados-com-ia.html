1O fluxo de análise com IA

Por que não colar a planilha no chat e pedir "me dá os insights"?

Porque um modelo de linguagem pode inventar um número com toda a confiança. Ele é ótimo para escrever o código da análise e para explicar o resultado; a conta em si tem de ser feita por código que você roda. O fluxo:

1. Pergunta de negócio

Específica: "qual canal resolve mais rápido e com mais sucesso?", e não "analise os dados".

2. Dados limpos e sem dado pessoal

Só as colunas que a pergunta precisa. Sem nome, CPF ou e-mail.

3. IA escreve o código

Peça código em pandas que responda à pergunta, e não a resposta direta.

4. Você roda e confere

Refaça uma das contas por outro caminho. Se as duas não batem, nada vai para o relatório.

5. IA ajuda a contar a história

Com os números conferidos na mão, peça o texto. Revise se o texto não exagerou o que os números dizem.

2O exemplo, rodado

Como a conferência vira parte do programa, e não um passo que você esquece?

"""Análise de dados com conferência (apostila de AI Builder, cap. 7).

A IA escreve a primeira versão do código; você confere os números com uma segunda conta
independente antes de colocar qualquer valor em um relatório.
Rodar:  pip install pandas  e depois  python analise.py
"""
import pandas as pd

# Dados fictícios de atendimentos de uma loja (mesmos números do capítulo).
dados = pd.DataFrame({
    "canal":   ["WhatsApp", "WhatsApp", "E-mail", "WhatsApp", "E-mail", "Telefone", "E-mail", "Telefone"],
    "minutos": [4, 6, 18, 5, 22, 9, 15, 11],
    "resolvido": [True, True, False, True, True, True, False, True],
})

# 1) A pergunta de negócio: qual canal resolve mais rápido e com mais sucesso?
resumo = dados.groupby("canal").agg(
    atendimentos=("minutos", "size"),
    minutos_medio=("minutos", "mean"),
    taxa_resolucao=("resolvido", "mean"),
).round(2)
print(resumo)

# 2) A conferência: refazer uma das contas por outro caminho.
email = dados[dados["canal"] == "E-mail"]["minutos"]
media_manual = sum(email) / len(email)
assert round(media_manual, 2) == resumo.loc["E-mail", "minutos_medio"], "as duas contas não batem"
print(f"Conferido: média do e-mail = {media_manual:.2f} min")

Saída da execução (feita na criação desta apostila):

          atendimentos  minutos_medio  taxa_resolucao
canal
E-mail               3          18.33            0.33
Telefone             2          10.00            1.00
WhatsApp             3           5.00            1.00
Conferido: média do e-mail = 18.33 min
Exemplo resolvido: ler sem exagerar
WhatsApp: média de 5 minutos e 100% resolvido. E-mail: 18,33 minutos e só 33% resolvido (1 de 3).
Conferência do e-mail na mão: (18 + 22 + 15) / 3 = 55 / 3 = 18,33. Bate com a tabela.
O que não dá para dizer: "o WhatsApp é 3,7 vezes melhor". São 8 atendimentos no total; com tão pouco dado, a conclusão honesta é "vale coletar mais antes de mudar o processo".
Erro comumAceitar a frase bonita que a IA escreveu sobre os dados sem checar se ela bate com a tabela. O texto costuma generalizar mais do que os números permitem.

3Dados pessoais e LGPD

A planilha tem nome, CPF e telefone de clientes. Posso colar no chat?

A Lei Geral de Proteção de Dados (Lei 13.709/2018) exige base legal e finalidade para tratar dado pessoal, e mandar a planilha para um serviço externo é tratamento. Em empresa, a regra prática: só use ferramentas aprovadas pela empresa e só com os dados necessários. Para análise, quase sempre dá para remover ou pseudonimizar as colunas pessoais antes.

Tabela com canal, minutos e se foi resolvido, sem identificar ninguém.

Sem dado pessoal, o risco é baixo.

A planilha completa de clientes, com CPF, para "a IA achar padrões".

Dado pessoal sem necessidade. Remova as colunas que a pergunta não usa.

Um processo sob segredo de justiça, para resumir, numa conta pessoal de IA.

Sigilo e ferramenta não aprovada. Só no ambiente que a empresa autorizou, se autorizar.

O código da análise, sem os dados, para a IA revisar.
