Tipos, strings, operadores e printf

Tipos primitivos, os três jeitos de guardar texto, operadores, printf e leitura pelo Serial.

Onde paramosNo Capítulo 4 você viu que variáveis guardam valores. Falta saber que tipos existem, como o texto é guardado (e por que há três jeitos), como comparar e como imprimir tudo isso com formato.

1Tipos primitivos

A variável precisa saber o que guarda.

int idade = 18;            // inteiro
float temperatura = 27.5;  // decimal
char letra = 'N';          // um único caractere (aspas simples)
String nome = "ESP 32";    // texto (classe do Arduino)
bool ligado = true;        // verdadeiro ou falso

Se a luz está ligada: sim ou não.

Dois estados possíveis: bool.

A temperatura 27,5 °C.

Tem parte decimal: float.

O número de pessoas na sala.

Contagem inteira: int.

A letra 'N' (um único caractere).

Um caractere, entre aspas simples: char.

A mensagem "Sistema ligado".

Texto com vários caracteres: String.
0 de 0 certas

No Monitor Serial, um float sai com 2 casas por padrão (20.50) e um bool sai como 1 ou 0, e não como true/false.

2Três jeitos de guardar texto

O texto é uma sequência de caracteres, e o final precisa ser marcado.

1. char array (C-string)

char palavra[6] = "ESP32";   // 5 letras, mas o array precisa de 6
índice012345
valorESP32\0

O sexto espaço guarda o caractere nulo \0, que marca onde o texto termina. Por isso o tamanho é sempre o número de caracteres visíveis + 1; char texto[5] = "ESP32"; é erro. palavra[1] vale 'S'. Um caractere usa aspas simples ('S'); um texto usa aspas duplas ("ESP32").

2. std::string e 3. String do Arduino

String texto = "ESP32";
texto += ": funcionando!";     // concatena (equivale a texto = texto + ...)
Serial.println(texto);

O std::string é da biblioteca padrão do C++. No ESP32 recomenda-se a classe String (S maiúsculo) do Arduino, que gerencia a memória sozinha. Mas há um ponto de atenção real de engenharia: String facilita a manipulação, porém pode fragmentar a memória, ruim em dispositivos com pouca RAM que rodam por muito tempo e concatenam muito. Em código de produção, às vezes o char array é preferível.

3Operadores e a pegadinha do = e ==

Atribuir não é comparar.

O resultado de uma comparação é um bool, que o Monitor Serial imprime como 1 (verdadeiro) ou 0 (falso). Comentários usam //.

Cuidado: divisão de inteirosEm C++, 10 / 4 com dois int dá 2, e não 2,5: a divisão entre inteiros é inteira. Para ter decimais, ao menos um dos lados precisa ser float (10.0 / 4). Teste junto com o printf na demo abaixo.

4Imprimir com formato: printf

Concatenar String é caro; o printf é direto.

float media = 27.456;
Serial.printf("A temperatura média é: %.2f ºC\r\n", media);   // 27.46

String nome = "ESP32";
Serial.printf("Placa: %s\r\n", nome.c_str());   // %s com String exige .c_str()

Marcadores: %d inteiro, %.2f decimal com 2 casas (%.7f, 7 casas), %c caractere, %s texto. O printf não quebra linha sozinho: coloque \n (ou \r\n, que funciona bem no Monitor Serial). Teste:

Operador ternário

bool ligado = true;
Serial.println(ligado ? "ligado" : "desligado");   // condição ? se_verdadeiro : se_falso
Exemplo resolvido: Celsius para Fahrenheit
Fórmula: F = C × 1,8 + 32. Para 27,5 °C: 27,5 × 1,8 = 49,5; 49,5 + 32 = 81,5 °F.
Em código: float c = 27.5; float f = c * 1.8 + 32; Serial.printf("%.1f C = %.1f F\r\n", c, f); imprime 27.5 C = 81.5 F.

5Ler comandos pelo Monitor Serial

A comunicação é de mão dupla.

void loop() {
  if (Serial.available() > 0) {                 // só entra se há algo no buffer
    String cmd = Serial.readStringUntil('\n');   // lê até o Enter
    cmd.trim();                                  // tira espaços e \r
    if (cmd == "ligar")         digitalWrite(LED, HIGH);
    else if (cmd == "desligar") digitalWrite(LED, LOW);
  }
}

Serial.available() diz se há algo esperando. Serial.readStringUntil('\n') é bloqueante: trava o loop(), acumulando caracteres até achar o \n ou estourar o tempo limite (timeout). Por isso se testa available() > 0 antes: é o padrão "verificar antes de bloquear". (O slide da aula fala em 5 s de tempo limite; o padrão do núcleo Arduino costuma ser 1 s, e Serial.setTimeout() muda. Confira na sua versão.)

6Fechamento do capítulo

Cola da prova

  • Tipos: int, float, char (aspas simples), String (aspas duplas), bool (imprime 1 ou 0).
  • char array precisa de tamanho + 1 por causa do \0. String é prático, mas pode fragmentar a memória.
  • = atribui; == compara. Divisão de inteiros é inteira: 10/4 = 2.
  • printf: %d, %.2f, %c, %s (com .c_str()); não quebra linha sozinho.
  • Ler pelo Serial: available() > 0 antes de readStringUntil('\n'), que bloqueia.

Teste rápido

Pergunta 1

Qual o tamanho mínimo do array para guardar a palavra 'ESP32' como char array?

O \0 marca o fim do texto e ocupa uma posição.
Pergunta 2

Quanto é 10 / 4 com dois int em C++?

A divisão entre inteiros descarta a parte decimal. Com float (10.0 / 4), seria 2,5.
Pergunta 3

Por que testar Serial.available() > 0 antes de readStringUntil?

readStringUntil bloqueia; verificar antes evita bloquear sem necessidade.
