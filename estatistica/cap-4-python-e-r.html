1Lógica, algoritmo e linguagem

A linguagem é o último passo, não o primeiro.

Três ideias, nesta ordem: lógica de programação (organizar instruções de forma coerente e em sequência), algoritmo (uma sequência finita, lógica e bem definida de instruções que realiza uma tarefa, como uma receita) e linguagem de programação (o conjunto de regras que permite escrever o algoritmo para o computador). O mesmo algoritmo pode ser escrito em Python, R ou outra linguagem.

Para ser uma linguagem de programação é preciso ter controle de fluxo (decidir), variáveis (guardar dados), operações lógicas e matemáticas (calcular e comparar) e execução de algoritmos. Por isso HTML não é linguagem de programação: é de marcação. Descreve o que aparece na tela, mas não tem condicional, nem laço, nem manipula dados sozinha.

Vibe coding e alucinaçãoProgramar sem entender o código, só copiando de uma IA, traz riscos: alucinação (código errado que parece certo), dificuldade de corrigir erros, dependência e aprendizado superficial. Um exemplo real aparece logo adiante: um material de aula traz log(a, base=b) em Python, que dá erro (a sintaxe é de R). Quem só copia não percebe; quem entende, testa e corrige.

Sobre o Python: linguagem de alto nível, orientada a objetos e de código aberto, criada por Guido van Rossum no CWI (Holanda), com início em 1989 e versão 1.0 em 1994. 4Decidir e repetir

Condicionais e laços, para o programa reagir e não repetir código à mão.

Os operadores lógicos são and (todas as condições verdadeiras), or (pelo menos uma) e not (inverte). Em R, &&, || e !. Acompanhe a decisão linha a linha:

# R: a mesma decisão
nota <- 7.5
frequencia <- 50
if (nota >= 7 && frequencia >= 75) {
  print("Aprovado!")
} else if (nota >= 5 && frequencia >= 75) {
  print("Recuperacao.")
} else {
  print("Reprovado.")
}

O for repete para cada elemento de uma sequência (número conhecido de vezes); o while repete enquanto uma condição for verdadeira, e precisa atualizar a variável para não virar laço infinito. Atenção: range(1, 6) vai de 1 a 5, o fim não entra. Aqui o laço calcula a média de quatro notas, a primeira medida da estatística descritiva:

# R: mesma média, sem laço (R é vetorizado)
notas <- c(7, 8.5, 6, 9)
mean(notas)    # 7.625

Para reaproveitar código, usa-se função: def area_triangulo(b, h): return (b * h) / 2 em Python e area_triangulo <- function(b, h) (b * h) / 2 em R. Funções dividem o programa em partes pequenas, reutilizáveis e testáveis.

5Objetos e o data frame

Onde os dados moram.

Declarar um objeto é atribuir valor (x = 5). Nomes começam com letra, sem espaço, sem acento (evite ç), maiúscula é diferente de minúscula e palavras reservadas (if, for) não valem. Python tem quatro tipos nativos de coleção:

TipoExemploOrdem?Muda?Repete?
Lista[2, 3, 6]simsimsim
Tupla(1, "a", True)simnãosim
Dicionário{"nome": "Maria", "idade": 28}ordem de inserção; acesso por chavesimchave única
Conjunto{"maçã", "banana"}nãosimnão
lista2 = [2, 3, 6, 9, 8, 5, 10]
lista2[2:5]     # [6, 9, 8]  (posição 2 até a 4; a 5 não entra)
lista2[10:]     # []         fatia fora do tamanho devolve lista vazia
lista2[10]      # IndexError: posição única inexistente dá erro
set([1, 2, 3, 2, 1])   # {1, 2, 3}  conjunto elimina duplicatas

Em R, o equivalente é o vetor c(2, 3, 6, 9, 8, 5, 10), e x[3:5] devolve 6, 9, 8 (posições de 1 a 7). Posição inexistente em R devolve NA, e não erro.

Para dados em tabela essas estruturas não bastam. O data frame é uma tabela de linhas e colunas em que cada coluna pode ter um tipo diferente, parecida com planilha ou com tabela de banco de dados. Em R é nativo; em Python vem da biblioteca pandas:

import pandas as pd
tabela = pd.DataFrame({"Nome": ["Ana", "Bruno"], "Idade": [25, 34]})
print(tabela)
#     Nome  Idade
# 0    Ana     25
# 1  Bruno     34

# R
tabela <- data.frame(Nome = c("Ana", "Bruno"), Idade = c(25, 34))

Comandos úteis: type(x) (classe do objeto), del x (apaga da memória), help("print") (documentação). Bibliotecas extras se instalam com pip install nome e se carregam com import; em R, install.packages("nome") e library(nome). As mais usadas: pandas e NumPy (dados), Matplotlib e Seaborn (gráficos), scikit-learn (machine learning).

6Ler e escrever arquivos

Quase todo erro de "meus dados estão estranhos" nasce aqui.

O arquivo precisa estar no diretório de trabalho (os.getcwd() em Python, getwd() em R) ou você passa o caminho completo. Dois parâmetros decidem se a leitura dá certo: sep (o separador de colunas) e decimal (o separador decimal). No Brasil, o CSV costuma usar ; como separador, porque a vírgula é o decimal. Teste as combinações:

# Python (pandas)
df = pd.read_csv("DadosAula.csv", sep=";", decimal=",", header=0)
df = pd.read_excel("DadosAula.xlsx", engine="openpyxl")   # .xlsx precisa do openpyxl
df.to_csv("Novo.csv", sep=";", index=False)               # index=False: sem a coluna 0, 1, 2...

# R
df <- read.csv2("DadosAula.csv")          # read.csv2 já assume sep = ";" e dec = ","
library(readxl); df <- read_excel("DadosAula.xlsx")
write.csv2(df, "Novo.csv", row.names = FALSE)
Para abrir no RStudioTodos os exemplos em R da apostila (capítulos 4, 5 e 6) estão num arquivo só: exemplos.R. Baixe, abra no RStudio e rode linha a linha com Ctrl+Enter. Eles foram executados no R 4.6.1 e os resultados batem com os comentários do código.
Confira sempre depois de lerTrês linhas salvam horas: df.shape (linhas e colunas, no R dim(df)), df.dtypes (tipo de cada coluna, no R str(df)) e df.head() (as primeiras linhas, no R head(df)). Se o arquivo mudar, o Python não atualiza sozinho: salve e rode de novo.

Teste rápido

Pergunta 1

Ao ler um CSV brasileiro com read_csv sem sep=';', o que costuma acontecer?

O separador do arquivo é ';' e o padrão do pandas é ','. Por isso a conferência de shape logo depois de ler.
Pergunta 2

Qual a diferença entre lista2[10:] e lista2[10] numa lista de 7 itens?

Fatias fora do tamanho são toleradas; posição única inexistente não.
Pergunta 3

Supondo que from math import sqrt, log já foi feito, qual item funciona em R mas dá erro em Python?

O argumento base= só existe no log do R. Em Python: math.log(8, 2).
