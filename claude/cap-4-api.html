1Chave e ambiente

O que preciso antes da primeira linha de código?

Uma conta na Claude Console (platform.claude.com), créditos e uma chave de API. A chave vai na variável de ambiente ANTHROPIC_API_KEY; o SDK de Python lê ela sozinho. Instalação: pip install anthropic. A regra do capítulo 1 da apostila de AI Builder vale aqui: a chave nunca entra no código nem no Git.

2A primeira chamada

Qual o mínimo para o Claude responder de dentro de um programa?

"""Primeira chamada à API do Claude (apostila do Claude, cap. 4).

Precisa de uma chave da Claude Console na variável de ambiente ANTHROPIC_API_KEY.
Rodar:  pip install anthropic   e depois   python primeira_chamada.py
"""
import anthropic

cliente = anthropic.Anthropic()  # lê ANTHROPIC_API_KEY do ambiente

resposta = cliente.messages.create(
    model="claude-sonnet-5-5",   # ID do modelo, conferido na página de modelos em 29/10/2026
    max_tokens=500,              # teto da resposta, em tokens
    system="Você é um tutor de programação. Responda em português, em no máximo 3 frases.",
    messages=[
        {"role": "user", "content": "O que é uma API, explicado para quem vem do Direito?"},
    ],
)

print(resposta.content[0].text)   # o texto da resposta
print(resposta.stop_reason)       # por que parou: end_turn, max_tokens, tool_use...
print(resposta.usage.input_tokens, resposta.usage.output_tokens)  # o que você paga
ParâmetroObrigatório?O que é
modelsimo ID do modelo (tabela do capítulo 1)
max_tokenssimo teto da resposta; o modelo pode parar antes
messagessima conversa: lista de {"role": "user" ou "assistant", "content": ...}
systemnãoo system prompt, como parâmetro separado (não como mensagem)

A resposta traz content (uma lista de blocos; o de texto tem .text), stop_reason e usage com os tokens. Os valores de stop_reason que você vai ver: end_turn (terminou), max_tokens (bateu o teto e cortou), stop_sequence e tool_use (quer usar uma ferramenta, capítulo 5).

Este código precisa de chave para rodar e não foi executado aqui. O exemplo do capítulo 5 tem um teste que roda sem chave.

Erro comumResposta cortada no meio e stop_reason igual a max_tokens. Não é bug: o teto foi baixo. Aumente max_tokens ou peça uma resposta mais curta.
Sem memória entre chamadasA API não lembra a conversa anterior. Para continuar, você reenvia o histórico inteiro em messages. E todo o histórico é cobrado como entrada a cada chamada.

3Tokens e custo

Quanto custa usar a API num projeto de verdade?

Token é um pedaço de texto (em média, menos que uma palavra). Você paga a entrada (system, histórico, documentos, definição de ferramentas) e a saída (o que o modelo escreve), com preço por milhão de tokens.

Exemplo resolvido: 1.000 chamadas no Sonnet 5.5
Cada chamada: 3.000 tokens de entrada e 500 de saída. Preço: US$ 2 e US$ 10 por milhão.
Entrada: 3.000 ÷ 1.000.000 × 2 = US$ 0,006. Saída: 500 ÷ 1.000.000 × 10 = US$ 0,005.
Uma chamada: US$ 0,011. Mil chamadas: US$ 11. Confira na demo abaixo, que abre com estes valores.

Como pagar menos, pela documentação: a Batch API (pedidos processados de forma assíncrona) custa 50% menos; o prompt caching cobra a leitura de um trecho repetido a uma fração do preço de entrada (10% do preço base em geral, 5% no Opus 5.5 e no Sonnet 5.5); e escolher o modelo menor que resolve. Fora isso: limite o tamanho da resposta e não reenvie histórico que não importa.

4Fechamento do capítulo

Cola da prova

  • Conta na Claude Console, chave em ANTHROPIC_API_KEY, pip install anthropic.
  • Obrigatórios: model, max_tokens, messages. system é parâmetro separado.
  • Resposta: blocos em content, stop_reason e usage.
  • A API não guarda a conversa: você reenvia o histórico, e ele é cobrado.
  • Custo = entrada × preço + saída × preço. Batch 50% off; cache lê a uma fração do preço.

Teste rápido

Pergunta 1

Qual destes NÃO é obrigatório em messages.create?

O system prompt é opcional. Os outros três são obrigatórios.
Pergunta 2

A resposta veio cortada e o stop_reason é max_tokens. O que houve?

max_tokens como motivo de parada significa que o teto definido por você foi alcançado.
Pergunta 3

1.000 chamadas no Opus 5.5 com 2.000 tokens de entrada e 1.000 de saída custam:

Entrada: 2.000 ÷ 1M × 4 = 0,008. Saída: 1.000 ÷ 1M × 20 = 0,020. Total 0,028 por chamada × 1.000 = US$ 28.
Pergunta 4

O seu chatbot reenviou um histórico enorme em cada chamada. O que acontece?

Tudo o que vai em messages é entrada. Histórico longo encarece cada nova chamada.
