1A história que esta apostila conta

Aprender Python não é decorar comandos. É aprender a pensar em passos: dividir o problema, achar padrões, abstrair e escrever uma regra que o computador possa seguir. Cada capítulo acrescenta uma peça e abre com a pergunta que a peça anterior deixou sem resposta.
