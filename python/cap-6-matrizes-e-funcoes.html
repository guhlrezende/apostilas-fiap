1Matriz: uma lista de listas

Uma tabela cabe numa variável só?

Uma matriz é uma estrutura bidimensional: cada elemento tem um índice de linha e um de coluna, ambos começando em 0. Em Python é simplesmente uma lista de listas, e se acessa com matriz[y][x]: y escolhe a linha, x a coluna.

matriz = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
]
matriz[1][2]    # 6: segunda linha, terceira coluna

Para percorrer, um for dentro do outro: o de fora escolhe a linha, o de dentro anda pelas colunas. Para acrescentar, remover e inserir, as mesmas operações de lista valem, aplicadas à linha certa:

Erro comumTrocar y e x. É matriz[y][x] (linha primeiro), e não [x][y]. E criar uma matriz com [[0] * 3] * 3 é uma armadilha: as três linhas são a mesma lista (lembra do b = a do Capítulo 4?). O certo: [[0] * 3 for _ in range(3)].

2Funções: blocos com nome

Escreva uma vez, use quantas vezes quiser.

Uma função é um bloco de código reutilizável, definido com def. Ela recebe parâmetros (entradas) e devolve um resultado com return:

def media(numeros):
    return sum(numeros) / len(numeros)

print(media([7, 8, 9]))   # 8.0

Acompanhe o controle entrando e saindo da função eh_primo. Repare que dentro dela as variáveis são as da função (n e d), e não as do programa principal:

return x print

print só mostra na tela. return devolve o valor a quem chamou, para você guardar numa variável ou usar numa conta. Uma função sem return devolve None.

Escopo (complemento)

Variáveis criadas dentro da função são locais: só existem lá. O mundo de fora não as enxerga, e a função não deveria depender de variáveis globais.

def saudacao(nome, idioma="pt"):       # idioma tem valor padrão
    if idioma == "pt":
        return f"Olá, {nome}!"
    return f"Hello, {nome}!"

saudacao("Ana")                # 'Olá, Ana!'
saudacao("Ana", "en")          # 'Hello, Ana!'
saudacao(idioma="en", nome="Bia")   # argumentos nomeados: a ordem não importa

Os exercícios de função, resolvidos

# calculadora com 4 funções
def soma(a, b): return a + b
def subtrai(a, b): return a - b
def multiplica(a, b): return a * b
def divide(a, b):
    if b == 0:
        return "não dá para dividir por zero"
    return a / b

# contar vogais
def conta_vogais(texto):
    return sum(1 for c in texto.lower() if c in "aeiou")

# fatorial: 5! = 5 * 4 * 3 * 2 * 1 = 120
def fatorial(n):
    resultado = 1
    for i in range(2, n + 1):
        resultado *= i
    return resultado

Cola da prova

  • Matriz = lista de listas. matriz[y][x]: linha primeiro, coluna depois, ambos a partir de 0.
  • Percorrer: for aninhado. Linha: append, insert, del, pop funcionam como em listas.
  • [[0] * 3] * 3 repete a mesma linha. Use compreensão: [[0] * 3 for _ in range(3)].
  • Função: def nome(parametros):; return devolve e encerra; sem return, devolve None.
  • Escopo: variável de dentro da função é local. return não é print.
  • Parâmetro com valor padrão (idioma="pt") e argumentos nomeados.

Teste rápido

Pergunta 1

Dada m = [[1, 2, 3], [4, 5, 6]], o que é m[1][0]?

O primeiro índice escolhe a linha (a de índice 1 é [4, 5, 6]) e o segundo a coluna (a de índice 0 é o 4).
Pergunta 2

Qual a diferença entre return e print dentro de uma função?

Com return você pode guardar o resultado (x = media(...)). Com print o valor aparece e se perde.
Pergunta 3

O que acontece quando uma função executa return False no meio do código?

return encerra a função naquele ponto, mesmo dentro de um laço, e devolve o valor.
