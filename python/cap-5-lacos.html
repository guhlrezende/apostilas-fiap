Onde paramosNo Capítulo 4 você guardou muitos valores numa lista. Falta fazer algo com cada um deles sem escrever o mesmo comando 100 vezes. É a ideia da repetição: um laço.

1for: percorrer uma sequência

"Para cada item desta coleção, faça isto."

O for percorre uma sequência (uma lista, uma string, um range). O número de voltas é conhecido: é o tamanho da sequência. A cada volta, a variável do laço assume o próximo valor.

for numero in [1, 2, 3, 4, 5]:
    print(numero)

for i in range(10):      # 0, 1, ..., 9
    print(i)

range(n) vai de 0 a n-1; range(a, b) de a a b-1; range(a, b, passo) pula de passo em passo. O padrão mais importante de todo laço é o acumulador: uma variável que começa num valor neutro e vai juntando algo a cada volta.

2while: repetir enquanto valer a condição

O laço que depende do que acontece durante a execução.

O while repete enquanto uma condição for verdadeira, e a avalia antes de cada volta. Use quando o número de repetições não é conhecido antes: "continue pedindo até digitar um número válido".

numero = int(input("Digite um número maior que 10: "))
while numero <= 10:
    numero = int(input("Não é maior que 10. Tente novamente: "))
Regra de bolsofor quando você sabe (ou pode calcular) quantas vezes vai repetir; while quando a parada depende de algo que só se descobre rodando.
Erro comum: loop infinitoÉ quando a condição do while nunca fica falsa, quase sempre porque você esqueceu de atualizar a variável de controle (contador = contador - 1). O programa "trava" sem mensagem de erro. Se acontecer, interrompa com Ctrl + C e releia: "o que muda a cada volta e leva a condição a falhar?"

3break, continue e o else do laço

Controle fino sobre cada volta.

  • break: sai do laço imediatamente.
  • continue: pula o resto desta volta e vai para a próxima.
  • else num laço (complemento): roda quando o laço terminou sem break. Útil em buscas: "se percorri tudo e não achei...".

Os exercícios de laço, resolvidos

# 1 a 50
for i in range(1, 51): print(i)

# soma de 1 a 10 (55) e produto de 1 a 5 (120)
soma, prod = 0, 1
for i in range(1, 11): soma += i
for i in range(1, 6):  prod *= i

# pares de 2 a 10: o terceiro argumento é o passo
for i in range(2, 11, 2): print(i)

# contagem regressiva de 10 a 1 com "Fogo!"
for i in range(10, 0, -1): print(i)
print("Fogo!")

# somar positivos até o usuário digitar um negativo
total = 0
n = float(input("Número: "))
while n >= 0:
    total += n
    n = float(input("Número: "))
print(total)
Complemento: enumerateQuando precisar do índice e do valor: for i, valor in enumerate(lista):. É mais limpo que for i in range(len(lista)). E o laço dos notebooks de ML (for k in range(1, 21)) é exatamente este padrão: testar cada valor de uma coleção.

4Fechamento do capítulo

Cola da prova

  • for: percorre uma sequência (número de voltas conhecido). while: repete enquanto a condição for verdadeira.
  • range(a, b, passo) vai de a a b - 1. range(10, 0, -1) conta para trás.
  • Acumulador: variável que começa neutra (0 na soma, 1 no produto) e junta algo a cada volta.
  • Loop infinito: a condição nunca fica falsa. Atualize a variável de controle; Ctrl + C para parar.
  • break sai do laço; continue pula a volta; o else do laço roda se não houve break.

Teste rápido

Pergunta 1

Quantas vezes executa for i in range(3, 8):?

O range inclui o início (3) e exclui o fim (8): 3, 4, 5, 6, 7 são 5 valores.
Pergunta 2

Por que este laço nunca termina? n = 5 / while n > 0: print(n)

Falta atualizar a variável de controle dentro do laço (por exemplo, n = n - 1).
Pergunta 3

Qual a soma de for n in range(1, 8) com if n == 3: continue e if n == 6: break?

O continue pula o 3 e o break encerra no 6 (sem somar). Sobram 1, 2, 4, 5.
