1if, elif e else

Uma pergunta de sim ou não decide o caminho.

Uma estrutura condicional executa (ou ignora) um bloco de código dependendo de uma condição. A condição é uma expressão que vira True ou False:

if idade >= 18:
    print("Você é maior de idade.")
else:
    print("Você é menor de idade.")

Para mais de duas saídas entra o elif ("senão se"). O Python avalia de cima para baixo e executa só o primeiro bloco cuja condição for verdadeira:

Cuidado: a indentação é a sintaxeEm Python não há chaves { }: o que pertence a cada bloco é definido pelo recuo (4 espaços, por convenção). A linha print("Fim") sem recuo não faz parte do if. Misturar espaços e tabs ou errar o recuo dá IndentationError.
Erro comum= não é ==. idade = 18 atribui; idade == 18 compara. Dentro de um if, use sempre ==. Outro clássico: if x == 1 or 2: está errado (o 2 sozinho é sempre verdadeiro). O certo é if x == 1 or x == 2: (ou x in (1, 2)).

3match-case: menus e faixas

Comparar uma variável com vários valores possíveis.

O match (Python 3.10 ou mais novo) compara um valor com cada case. O case _ é o curinga, que pega o que sobrou (o equivalente ao else). Dentro de um case, o | lê como "ou", e um guard (case ... if condição) acrescenta uma condição extra:

idade = 15
match idade:
    case n if n <= 12:
        print("criança")
    case n if n <= 17:
        print("adolescente")
    case _:
        print("adulto")

Menu clássico do exercício (1 ver perfil, 2 editar perfil, 3 sair):

opcao = int(input("1-Ver perfil  2-Editar perfil  3-Sair: "))
match opcao:
    case 1:
        print("Mostrando o perfil")
    case 2:
        print("Editando o perfil")
    case 3:
        print("Saindo")
    case _:
        print("Opção inválida")
Quando usar qualPara faixas e condições compostas, o if/elif costuma ser mais claro. O match brilha para valores exatos (menus, dias, comandos). Uma pegadinha: dentro de case, um nome sozinho (como o n acima) captura o valor, e não compara com uma variável existente.

4Fechamento do capítulo

Cola da prova

  • if/elif/else: executa o primeiro bloco verdadeiro, de cima para baixo.
  • A indentação define o bloco. Sem chaves.
  • = atribui; == compara. Em Python: and, or, not (nada de && ou ||).
  • Bissexto: (ano % 4 == 0 and ano % 100 != 0) or ano % 400 == 0.
  • match/case (Python 3.10+): menus e valores exatos; | é "ou"; case _ é o curinga; guard com if.
  • x == 1 or 2 é um erro clássico: escreva x == 1 or x == 2.

Teste rápido

Pergunta 1

Com nota = 8, qual bloco da cadeia if nota >= 7 / elif nota >= 5 / else executa?

O Python para no primeiro verdadeiro. Como 8 >= 7, executa esse bloco e ignora o elif e o else, mesmo que 8 >= 5 também fosse verdadeiro.
Pergunta 2

Qual condição diz 'maior de idade E com carteira'?

Em Python o E lógico é and. O && é de outras linguagens.
Pergunta 3

O ano 1900 é bissexto?

A regra tem exceções em cascata: múltiplos de 100 não são bissextos, a menos que sejam múltiplos de 400 (como 2000).
