1Lista: a fila de caixas numeradas

Uma variável só, muitos valores, na ordem.

Uma lista é uma coleção ordenada (a posição faz parte da identidade do dado) e mutável (dá para mudar o conteúdo depois de criada). O índice começa em 0, e -1 pega o último elemento sem você calcular len(lista) - 1.

numeros = [1, 2, 3, 4, 5]
nomes   = ["Alice", "Bob", "Charlie"]
mista   = [1, "Bob", 3.14, True]   # tipos misturados são permitidos
vazia   = []

numeros[0]    # 1: o primeiro
numeros[-1]   # 5: o último

Para que serve: armazenar e organizar dados, iterar sobre eles (Capítulo 5), simular filas e pilhas, guardar dados estruturados (uma lista de listas é uma tabela, Capítulo 6) e passar coleções para funções. Brinque com as operações e com as fatias:

2Mutável: a pegadinha do "b = a"

Você achou que copiou a lista. Não copiou.

Em Python, uma variável guarda uma referência ao objeto. Quando você escreve b = a com listas, os dois nomes apontam para a mesma lista. Quem muda por um nome muda para o outro. Acompanhe:

Para uma cópia independente, use a.copy() (ou a[:], ou list(a)). Esse é o mesmo problema que faz uma função que recebe uma lista poder alterar a lista de quem a chamou.

Complemento: list comprehension

Uma forma compacta e "pythônica" de construir listas a partir de outras:

quadrados = [x ** 2 for x in range(1, 6)]          # [1, 4, 9, 16, 25]
pares     = [x for x in range(10) if x % 2 == 0]   # [0, 2, 4, 6, 8]

nums = [4, 8, 15, 16]
sum(nums)                              # 1) soma: 43
", ".join(["a", "b", "c"])           # 2) juntar strings: 'a, b, c'
max(nums), min(nums)                    # 3) maior e menor: (16, 4)

[x * 2 for x in nums]                  # 6) cada número vezes 2
all(len(s) > 3 for s in ["casa", "sol"])  # 7) todas com mais de 3 letras? False
sorted(nums, reverse=True)          # 8) ordem decrescente

4Fechamento do capítulo

Cola da prova

  • Lista: ordenada e mutável. Índice começa em 0; -1 é o último.
  • append (final), insert (posição), extend (junta elementos), remove (por valor), pop (por índice, e devolve).
  • sort() e reverse() mudam no lugar e devolvem None; sorted() devolve uma cópia.
  • b = a não copia a lista. Use a.copy().
  • tupla (imutável), dicionário (chave → valor), conjunto (sem repetição).
  • Fatia l[a:b] vai do índice a ao b - 1.

Teste rápido

Pergunta 1

Dada l = [10, 20, 30, 40], o que é l[1:3]?

A fatia começa no índice 1 (incluído) e vai até o 3 (excluído): fica o 20 e o 30.
Pergunta 2

Depois de a = [1, 2]; b = a; b.append(3), quanto vale a?

Atribuir uma lista a outra variável só cria outro nome para o mesmo objeto.
Pergunta 3

Qual a diferença entre remove(5) e pop(5)?

remove procura pelo valor. pop(i) usa o índice, e ainda devolve o elemento removido.
