1input(): sempre texto

O usuário digitou 7. O que chegou ao programa?

A função input() lê o que a pessoa digita e sempre devolve um str (texto), mesmo que ela digite um número. Para fazer conta, você precisa converter: int(...) para inteiros, float(...) para números com casas decimais. Esse é o bug número 1 dos primeiros exercícios.

Erro comumEsquecer de converter. Sem o int(), '7' + '5' vira '75' (concatenação), e '7' * 2 vira '77'. Se a pessoa digitar casas decimais e você usou int(), o Python dá ValueError: use float(). (No Capítulo 9 você vê como tratar essa digitação errada sem o programa quebrar.)

3f-strings: texto com variáveis dentro

Montar uma frase com valores sem somar pedaços de texto.

Uma f-string começa com f antes das aspas e aceita variáveis (e até contas) dentro de { }. Depois de dois-pontos vem o formato: {valor:.2f} mostra 2 casas decimais. Teste vários:

Em aula só apareceram os formatos :.2f e :.4f; os demais da demo (vírgula, %, notação científica, largura e alinhamento) são complemento.

LembraO formato só muda o que aparece no print. A variável continua guardando o valor completo. Por isso você formata na hora de mostrar, e não antes de calcular (arredondar no meio da conta acumula erro).

4Fechamento do capítulo

Cola da prova

  • input() sempre devolve str. Converta com int() ou float().
  • int() quebra com casas decimais digitadas: use float() nesse caso.
  • Parênteses mandam na ordem das contas: (Fah - 32) * 5 / 9.
  • f-string: f"texto {variavel:.2f}". O formato só afeta a saída.
  • int(2.5) corta a parte decimal (dá 2); é como se calculam horas e minutos separados.

Teste rápido

Pergunta 1

O que print(input() + input()) mostra se o usuário digitar 3 e depois 4?

Os dois input() devolvem texto, e + entre textos concatena: '3' + '4' = '34'.
Pergunta 2

Com x = 2.0 / 3, o que mostra print(f"{x:.2f}")?

O formato só atua na saída. A variável mantém o valor completo.
Pergunta 3

Para ler a temperatura 36.5 digitada, qual conversão usar?

int('36.5') dá ValueError. Com casas decimais, é float.
