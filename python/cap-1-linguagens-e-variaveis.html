1Por que Python

Antes do primeiro comando: com que ferramenta estamos trabalhando?

Python foi criado por Guido van Rossum e lançado em 1991, no CWI, na Holanda, com um objetivo bem claro: ter uma sintaxe limpa e fácil de ler, inspirada na linguagem ABC. (O nome vem do grupo de humor Monty Python, e não da cobra.) Isso importa na prática: uma linguagem pensada para a leitura humana deixa você entender o código dos outros sem decorar símbolos.

Python é de alto nível: fica perto da linguagem humana e esconde o hardware. Você escreve soma = 2 + 2 sem saber como o processador guarda o número em binário. Linguagens de baixo nível (como Assembly) mostram esses detalhes. O preço da abstração é velocidade de execução; o ganho é velocidade de desenvolvimento, e no começo é isso que importa.

2Compilada, interpretada, transpilada

Quem traduz o seu código, e quando?

Compilada

O código é todo traduzido para código de máquina antes de rodar, gerando um executável. Rápida; mas qualquer mudança exige recompilar. Ex.: C, C++, Rust.

Interpretada

O código é traduzido durante a execução, linha a linha. Você edita e testa na hora. Ex.: Python.

Transpilada

Traduz de uma linguagem de alto nível para outra de alto nível. Ex.: TypeScript vira JavaScript. (complemento)

Você escreve um arquivo .py e o roda direto, e um erro de execução só aparece quando a linha problemática é executada (erros de sintaxe aparecem antes de rodar qualquer linha).

Interpretada: o Python traduz e executa enquanto lê.

Você precisa gerar um executável antes de testar, e qualquer mudança exige gerar de novo (é o passo de build de um projeto C++).

Compilada: a tradução completa vem antes da execução.

O código em TypeScript é convertido em JavaScript, que o navegador entende.

Transpilada: de uma linguagem de alto nível para outra de alto nível.

Complemento: Python também "compila"Na verdade o Python traduz seu código para um formato intermediário (bytecode, os arquivos .pyc) e só então o interpreta. Por isso se diz "interpretada" no sentido prático: você não gera um executável nativo. O detalhe mostra que a divisão não é tão rígida quanto o slide sugere.

3Variáveis, constantes e tipos

Uma caixa com nome, e o que cabe nela.

Uma variável é um nome associado a um valor na memória, e o valor pode mudar. Uma constante é um valor que não deveria mudar: Python não impede, mas por convenção escreve-se em MAIÚSCULAS (PI = 3.14159). Marcar algo como constante evita que alguém sobrescreva sem querer um valor que devia ser fixo, como uma taxa ou um limite de tentativas.

Cada valor tem um tipo. Python é dinamicamente tipado: você não declara o tipo (como int x = 5 em C), o interpretador descobre pelo valor.

4Um desafio clássico: trocar A e B

Parece trivial, e tem uma armadilha.

O slide propõe: dadas duas variáveis, trocar o conteúdo de uma pela outra. A tentativa ingênua (a = b e depois b = a) falha, porque a primeira linha já apagou o valor antigo de a. A solução clássica usa uma variável temporária:

Em Python existe a forma curta a, b = b, a, que faz a mesma troca numa linha. Vale conhecer as duas: a temporária mostra a lógica, e a curta é a que você usa no dia a dia.

5Fechamento do capítulo

Cola da prova

  • Python: criada por Guido van Rossum em 1991, de alto nível e feita para ser legível.
  • Compilada: traduz tudo antes. Interpretada: traduz enquanto executa. Transpilada: converte para outra linguagem de alto nível.
  • Variável muda; constante (em MAIÚSCULAS, por convenção) não deveria.
  • Tipos básicos: int, float, str, bool (e list). Tipagem dinâmica.
  • / sempre devolve float; // é divisão inteira; % é o resto; ** é potência.
  • Para trocar duas variáveis: use uma temporária, ou a, b = b, a.

Teste rápido

Pergunta 1

Qual o resultado de 17 // 5 e de 17 % 5?

17 dividido por 5 dá 3 com resto 2. // devolve o quociente inteiro (3), e % o resto (2). 17 / 5 seria 3.4.
Pergunta 2

Por que a = b seguido de b = a NÃO troca os valores?

Depois de a = b, ambos valem o valor de b. Faltou guardar o valor antigo de a em algum lugar, a variável temporária.
Pergunta 3

type(3.0) devolve:

O tipo vem da forma como o valor é escrito. 3 é int; 3.0 é float.
