1A história que esta apostila conta

Esta apostila é complemento: nada dela foi dado em aula. Ela continua a de Terminal e Git e assume o Git básico dos capítulos 5 e 6 de lá (commit, branch, merge, remoto, push). Aqui o foco é o que o GitHub acrescenta. Primeiro a conta e o repositório, depois como o seu computador conversa com ele e como você prova quem é. Em seguida, o trabalho em equipe: issues, branches, pull request e os três tipos de merge, fork e contribuição. Por fim, o que protege tudo isso: regras para a main, Actions, releases, segurança, recuperação de erros e um perfil honesto.

O Git eu rodei de verdade, com repositórios locais fazendo o papel do GitHub. Tudo que depende do site (PR real, revisão, Actions rodando, proteção de branch, Pages, releases, secret scanning) vem marcado como não testado aqui. Eu não usei nenhuma conta do GitHub para escrever isto. Preços e limites de plano não aparecem como fato.

Onde esses pontos aparecem, está escrito confira.
