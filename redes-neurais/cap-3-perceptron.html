2O Perceptron por dentro

Entradas → pesos → soma → degrau → saída.

z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b      # soma ponderada
ŷ = f(z),   f(z) = 1 se z ≥ 0, senão 0  # função degrau

É exatamente o neurônio do Capítulo 1, com a ativação degrau. E a fronteira de decisão é a reta onde z = 0: de um lado a saída é 1, do outro, 0. O bias desloca essa reta; sem ele, ela seria obrigada a passar pela origem.

A regra de aprendizado

Para cada exemplo, o Perceptron prevê e compara com a resposta certa. Só se errar, ajusta:

wᵢ ← wᵢ + η · (y − ŷ) · xᵢ
b ← b + η · (y − ŷ)η é a taxa de aprendizado, y a resposta correta, ŷ a previsão e (y − ŷ) o erro.
Exemplo resolvido: treinando a porta AND
Estado inicial: w₁ = 0, w₂ = 0, b = 0, η = 0,1. Exemplo: (x₁ = 1, x₂ = 0), resposta correta y = 0.
z = 0·1 + 0·0 + 0 = 0. Como z ≥ 0, a previsão é ŷ = 1. Errou, porque y = 0.
Erro: y − ŷ = 0 − 1 = −1.
w₁ ← 0 + 0,1·(−1)·1 = −0,1; w₂ ← 0 + 0,1·(−1)·0 = 0; b ← 0 + 0,1·(−1) = −0,1.
O ciclo se repete por todos os exemplos, por várias épocas, até parar de errar.

3Treine você: AND, OR e o problema do XOR

Duas portas funcionam. A terceira não tem solução.

AND e OR são linearmente separáveis: uma única reta separa os 0 dos 1. O XOR ("um ou outro, mas não os dois") não é: não existe uma reta que separe (0,0) e (1,1) de (0,1) e (1,0). Por mais épocas que você rode, o Perceptron nunca zera os erros no XOR. Foi essa prova, de Minsky e Papert (1969), que paralisou a pesquisa em redes neurais por anos. A saída, décadas depois: empilhar neurônios em camadas, o assunto do Capítulo 5.

Cuidado: > ou ≥?Algumas fontes usam z > 0 para disparar, e outras z ≥ 0. A diferença só aparece quando z é exatamente zero. Neste capítulo e nos notebooks da aula a regra é z ≥ 0. Em planilha, confira qual comparação a fórmula usa.

4Fechamento do capítulo

Cola da prova

  • Perceptron (Rosenblatt, 1958): z = Σ wᵢxᵢ + b e degrau. Um neurônio que aprende.
  • Regra: w ← w + η·(y − ŷ)·x e b ← b + η·(y − ŷ), só quando erra.
  • A fronteira de decisão é uma reta; o bias a desloca.
  • AND e OR são linearmente separáveis. XOR não é: o Perceptron nunca converge (livro Perceptrons, 1969; primeiro inverno da IA nos anos 1970).
  • A saída: empilhar camadas (MLP) com backpropagation (1986).

Teste rápido

Pergunta 1

Com w₁ = w₂ = 0, b = 0, η = 0,1, a entrada (1, 1) e resposta y = 0, o Perceptron (degrau com ≥ 0) acerta?

z = 0 e, com ≥ 0, a saída é 1. O erro (0 − 1) = −1 corrige cada peso em η·erro·x = −0,1, e o bias em −0,1.
Pergunta 2

Por que o XOR não pode ser aprendido por um Perceptron simples?

O Perceptron só desenha uma fronteira reta. O XOR exige uma fronteira curva ou duas retas.
Pergunta 3

Quando o Perceptron atualiza os pesos?

Se o erro (y − ŷ) é zero, os termos de ajuste são zero e nada muda.
