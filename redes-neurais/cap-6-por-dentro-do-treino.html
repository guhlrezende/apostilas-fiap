1Backpropagation com números

Dois pesos, uma entrada, um passo de ajuste.

Rede minúscula: uma entrada x, um neurônio oculto com peso w₁ e ativação ReLU, e uma saída com peso w₂ (linear). Ou seja: h = ReLU(w₁·x) e ŷ = w₂·h. A perda é o erro ao quadrado: L = (ŷ − y)².

Exemplo resolvido: um passo completo
Dados: x = 2, y = 3 (resposta correta), w₁ = 0,5, w₂ = 1,0, taxa η = 0,1.
Passada para frente: z = w₁·x = 1; h = ReLU(1) = 1; ŷ = w₂·h = 1; L = (1 − 3)² = 4.
Passada para trás (regra da cadeia, da saída para a entrada): dL/dŷ = 2(ŷ − y) = −4.
dL/dw₂ = dL/dŷ · h = −4 · 1 = −4. dL/dh = dL/dŷ · w₂ = −4.
A ReLU deixa passar o gradiente (z > 0, derivada 1). dL/dw₁ = dL/dh · x = −4 · 2 = −8.
Atualização (w ← w − η · gradiente): w₁ = 0,5 − 0,1·(−8) = 1,3; w₂ = 1,0 − 0,1·(−4) = 1,4.
Conferindo: h = 1,3·2 = 2,6; ŷ = 1,4·2,6 = 3,64; L = (3,64 − 3)² = 0,4096. A perda caiu de 4 para 0,41 em um passo.

Os gradientes são negativos (o erro diminui quando o peso aumenta), por isso o sinal de menos da fórmula os transforma em soma. Numa rede real é a mesma conta, repetida para milhões de pesos, em lotes de exemplos, com o auxílio de bibliotecas que calculam as derivadas automaticamente.

2Funções de perda

A perda define o que significa "errar".

O RMSE do Capítulo 5 é só a raiz do MSE, para voltar à unidade original (kWh).

3Épocas, lotes e otimizadores

Como milhares de passos viram um treino.

  • Época: uma passada completa por todos os exemplos de treino.
  • Lote (batch): o grupo de exemplos usado para calcular um passo. Em um exemplo hipotético com 273 exemplos e lote de 32 (o MLPRegressor usa por padrão lotes de até 200), uma época tem 9 passos (8 de 32 e 1 de 17).
  • SGD (gradiente descendente estocástico): atualiza com o gradiente de cada lote. Simples, mas sensível à taxa de aprendizado.
  • Adam: ajusta o passo de cada peso com base no histórico dos gradientes. É o padrão em muitos projetos e é o otimizador padrão do MLPRegressor do scikit-learn.

Como evitar o overfitting na prática

  • Regularização L2: acrescenta à perda uma penalidade pelo tamanho dos pesos (no scikit-learn, o parâmetro alpha).
  • Dropout: desliga neurônios ao acaso durante o treino.
  • Early stopping: acompanhar a perda numa parte reservada dos dados (validação) e parar quando ela volta a subir.
  • Mais dados, de qualidade e variados.
Três conjuntosTreino ajusta os pesos. Validação ajuda a escolher hiperparâmetros e a hora de parar. Teste só é usado uma vez, no fim, para estimar o desempenho real.

4Fechamento do capítulo

Cola da prova

  • Backpropagation = regra da cadeia da saída para a entrada, para saber quanto cada peso contribuiu para a perda.
  • No exemplo: L = 4 → gradientes −8 e −4 → pesos 1,3 e 1,4 → ŷ = 3,64 → L = 0,4096.
  • Perda: MSE/MAE na regressão; entropia cruzada na classificação.
  • Época = passada completa; lote = grupo por passo. Adam e SGD são otimizadores.
  • Contra o overfitting: regularização, dropout, early stopping, mais dados. Teste só no fim.

Teste rápido

Pergunta 1

No exemplo, dL/dw₁ = −8. Com η = 0,1, qual o novo w₁ (partindo de 0,5)?

w₁ − η·gradiente = 0,5 − 0,1·(−8) = 1,3. Gradiente negativo aumenta o peso.
Pergunta 2

Qual perda é adequada para prever um valor contínuo, como preço?

Regressão usa perdas de distância; as entropias cruzadas são para probabilidades.
Pergunta 3

O que é early stopping?

A partir de certo ponto a rede só memoriza o treino; parar antes ajuda a generalizar.
