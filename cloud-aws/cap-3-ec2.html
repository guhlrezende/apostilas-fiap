1EC2: o computador por hora

Uma máquina inteira, sem comprar nada.

O EC2 (Elastic Compute Cloud) fornece a infraestrutura computacional: processador, memória, armazenamento, rede e sistema operacional. Ele cria máquinas virtuais, chamadas na AWS de instâncias. A AWS gerencia os hosts físicos; você enxerga e administra só a instância (sistema operacional e aplicação). Dá para rodar várias instâncias ao mesmo tempo, isoladas entre si, na mesma infraestrutura.

Toda instância nasce de uma AMI (Amazon Machine Image): uma imagem pronta que funciona como molde. A instância é uma cópia em execução da AMI, e dá para criar várias instâncias idênticas a partir da mesma imagem.

2Os três IPs e o disco

O IP público muda quando a máquina reinicia.

TipoCaracterísticas
IP públicoatribuído dinamicamente; muda a cada reinício; costumava ser gratuito, mas hoje a AWS cobra por hora todo endereço IPv4 público (confira a página de preços da VPC) da instância; não pode ser movido entre instâncias
IP privadousado nas sub-redes internas da VPC; mantido mesmo com o reinício
IP elásticofixo; tem cobrança por hora (como os demais IPv4 públicos); pode ser movido entre instâncias

Quem aponta um domínio para o IP público quebra o site a cada reinício. O IP elástico resolve isso, ao custo de pagar por ele. E o disco? O EBS (Elastic Block Store) é o volume de armazenamento da VM, como o C: ou /dev/sda1: dá para anexar mais espaço a uma instância existente, e ele persiste mesmo se a instância for parada. Já instâncias com "armazenamento local" (como as c6gd, com SSD NVMe) têm um disco muito rápido que não sobrevive à parada da instância (complemento).

3Exercício: um site em uma VM Linux

Do clique em "Launch" ao navegador mostrando a página.

1. Criar a instância

Escolha a AMI (Amazon Linux), o tipo (uma instância pequena; as pequenas costumam aparecer em laboratórios, mas o tipo aceito no nível gratuito muda, confira o vigente) e gere o par de chaves: baixe a chave privada, necessária para o SSH.

2. Liberar as portas no Security Group

SSH (porta 22) para administrar pelo terminal; HTTP (80) e HTTPS (443) para o site ser acessado. O Security Group é o firewall da instância.

3. Conectar por SSH

Com a chave privada, abra o terminal da instância.

4. Instalar e iniciar o Apache

Comandos abaixo. start liga agora; enable liga a cada boot.

5. Escrever a página

Edite /var/www/html/index.html.

6. Abrir o IP público

Digite o IP público da instância no navegador. O site aparece.

7. Encerrar a instância

Terminate instance ao terminar, para não continuar gastando crédito.

# atualizar a lista de pacotes (yum é o gerenciador do Amazon Linux)
sudo yum update

# instalar o servidor web Apache (o pacote se chama httpd); -y confirma sozinho
sudo yum install httpd -y

# iniciar agora, e iniciar sempre que a máquina ligar
sudo systemctl start httpd
sudo systemctl enable httpd        # (atalho: sudo systemctl enable --now httpd)

sudo vim /var/www/html/index.html  # a página inicial do site
start x enableO start liga o serviço só nesta sessão: se a instância reiniciar, o Apache não volta sozinho. O enable não liga nada agora; apenas marca para iniciar no próximo boot. Por isso se usam os dois.

E uma VM Windows?

O fluxo é parecido, mas o acesso remoto é por RDP (Remote Desktop Protocol, porta 3389), e não por SSH. A chave gerada na criação serve para decifrar a senha de administrador que a AWS gera; depois, conecta-se com o cliente de Área de Trabalho Remota.

Cuidado: porta aberta é porta de entradaLiberar o SSH (22) ou o RDP (3389) para 0.0.0.0/0 deixa a administração da máquina exposta à internet inteira. Em uso real, limite a origem ao seu IP. (Capítulo 7.)

4Fechamento do capítulo

Cola da prova

  • EC2: máquinas virtuais (instâncias) criadas a partir de uma AMI. A AWS gerencia o hardware; você, a instância.
  • Famílias: propósito geral (T, M), processamento (C), memória (R, X), armazenamento (I, D), acelerada (P, G).
  • IP público muda a cada reinício; privado permanece; elástico é fixo, pago e movível.
  • EBS é o disco da VM e persiste. Armazenamento local (NVMe) é muito rápido, mas não sobrevive à parada.
  • Linux: SSH (22), HTTP (80), HTTPS (443). Windows: RDP (3389). O Security Group é o firewall.
  • start liga agora; enable liga no boot. Termine a instância ao acabar.

Teste rápido

Pergunta 1

Por que apontar um domínio para o IP público de uma instância é arriscado?

O IP público é dinâmico. Para endereço fixo, use o IP elástico.
Pergunta 2

Qual porta libera o acesso remoto a uma VM Windows?

No Linux o acesso administrativo é por SSH. No Windows, por RDP.
Pergunta 3

O que faz systemctl enable httpd?

Para ligar agora é o start. Os dois resolvem problemas diferentes: o 'agora' e o 'depois de reiniciar'.
