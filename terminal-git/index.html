1A história que esta apostila conta

Esta apostila é complemento: nada dela foi dado em aula. Ela anda em degraus. Primeiro você aprende a falar com o computador por texto (terminal, shell, arquivos). Depois a ligar comandos pequenos para fazer algo maior (pipes, redirecionamento, grep, awk). Em seguida vem o que faz isso útil de verdade: permissões, variáveis, scripts, processos, curl e SSH. Por fim, o Git guarda o histórico e o GitHub leva isso para o trabalho em equipe.

Em todo comando que existe nos dois mundos, mostro o Git Bash e o PowerShell. O que eu consegui rodar vem sem aviso; o que não consegui vem marcado como não testado aqui.
